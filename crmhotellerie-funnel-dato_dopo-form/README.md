# CRM Hotel — pagine dopo il form (seconda cartella)

Stesso progetto di `../crmhotellerie-funnel-dato_def/`, da usare per le pagine che il lead vede **dopo** aver compilato il form Zoho:

- `/demo-sbloccata/` ← indirizzo da impostare come reindirizzamento del form Zoho
- `/prenota-consulenza/`
- `/grazie/`

Anteprima: `npm run serve` (porta 4329) oppure doppio clic su `Anteprima sito.command`; poi apri http://localhost:4329/demo-sbloccata/.
Zip: `npm run package` → `deploy/crm-hotellerie-dopo-form-latest.zip`.
